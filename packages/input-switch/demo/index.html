input-switch Demo

Explicit label

<input-switch id="input-switch-1"></input-switch> <label for="input-switch-1">switch</label>

Implicit label

<label><input-switch></input-switch> switch</label>

checked attribute

<label><input-switch checked=""></input-switch> switch</label>

disabled attribute

<label><input-switch disabled=""></input-switch> switch</label>

disabled and checked attribute

<label><input-switch disabled="" checked=""></input-switch> switch</label>

storage-key attribute

<label><input-switch storage-key="switch6"></input-switch> switch</label>

Form submission

<form>
  <p><label><input-switch name="switch1" value="1"></input-switch> switch</label></p>
  <p><label><input-switch name="switch2" value="1" checked=""></input-switch> switch</label></p>
  <p><button>Submit</button> <button type="reset">Reset</button></p>
</form>

* Values are not sent in browsers that do not support ElementInternals. As of February 2024, Firefox 93+, Safari 16.4+ and Chrome 77+ is supported.
